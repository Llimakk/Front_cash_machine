# Репозиторий фронтенда проекта "Банкомат"

## Связанный репозиторий
Бэкенд: https://github.com/Llimakk/RIP/tree/SSR

## Описание проекта
Система «Банкомат» представляет собой веб-сервис, включающий веб-приложение и нативное приложение для выбора купюр и выполнения операций по снятию наличных средств.

Цель системы — автоматизация процесса снятия наличных с банковских карт, а также предоставление пользователям удобного доступа к информации о доступных купюрах и выполненных операциях.

## Функциональные возможности

### Пользователь (владелец карты)
- просмотр доступных купюр;
- выполнение операций снятия наличных;
- просмотр истории операций.

### Операционист
- подтверждение или отклонение операций снятия;
- редактирование информации о купюрах;
- просмотр операций всех пользователей.

### Гость
- просмотр актуальной информации о купюрах;
- взаимодействие с системой через мобильное приложение.

## Архитектура и технологии

Веб-сервис реализован на фреймворке Django и взаимодействует со следующими компонентами:
- MinIO — для хранения файлов;
- Redis — для хранения активных пользовательских сессий;
- PostgreSQL — основная система управления базами данных.

При выходе пользователя из системы его сессия удаляется из Redis.

В качестве языка программирования выбран Python благодаря его популярности и удобству. Использование Django обусловлено наличием встроенной ORM, административной панели и широкого набора библиотек для работы с API.

Один веб-сервис используется как для веб-приложения, так и для десктопного приложения, разработанного с использованием Tauri.

В соответствии с политикой импортозамещения в качестве СУБД выбрана PostgreSQL, являющаяся индустриальным стандартом.

## Требования

- MinIO (RELEASE.2022-10-15T19-57-03Z и выше)
- Redis (6.2.16 и выше)
- Python (3.10 и выше)
- Django (4.1 и выше)
- PostgreSQL (12.2 и выше)
- Node.js
- Docker
